# PCモニタリング

```powershell
python -m pip install -r pc/requirements.txt
python pc/monitor.py
```

`pc/monitor.py` の `PORT`（初期値 `COM3`）をESP32のポート番号に合わせてください。
Arduino IDEやPlatformIOなどのシリアルモニターは閉じておきます。

115200bpsで、`cpu` と `ram` の使用率を改行区切りのJSONとして送ります。
接続ごとにESP32の起動を2秒待ってから、約1秒間隔で最新の使用率を計測・送信します。
ESP32ファームウェアの変更や再書き込みは不要です。

ポートが見つからない場合やUSB切断・送信タイムアウト時は、ポートを閉じ、
2秒待って同じポートへの接続を繰り返します。復旧すると送信が自動再開します。
送信のタイムアウトは1秒です。接続中・起動待機中・再接続待機中のいずれも
Ctrl+Cで終了できます。再接続時にポート番号が変わった場合は、`PORT` を変更して
再起動してください（ポート自動検出は未対応）。

## 自動テスト

リポジトリのルートから実行します。USB機器は不要です。

```powershell
python -m unittest discover -s pc/tests -v
```

## 実機確認手順（Windows / ESP32）

1. ESP32を接続して起動し、コンソールのJSONとLCDのCPU・RAM数値およびバーが
   約1秒間隔で更新されることを確認します。
2. 送信中にUSBを抜きます。プログラムが終了せず、エラーと再接続の案内が出て、
   未接続の間は約2秒ごとに接続を試すことを確認します。
3. 同じCOM番号でUSBを接続し直します。接続後の2秒の起動待機と約1秒の計測後に、
   最新の使用率の送信とLCD更新が自動再開することを確認します。抜き差しを数回繰り返します。
4. USB未接続でプログラムを起動し、再試行が継続すること、USBを接続すると
   自動で送信が始まることを確認します。
5. 正常送信中・接続後の起動待機中・未接続での再試行待機中それぞれでCtrl+Cを押し、
   終了メッセージが出てトレースバックなしで終了することを確認します。
   直後に再起動し、ポートを再び開けることも確認します。

実機ではUSBドライバーの切断通知、ポート番号の維持、ESP32の再起動時間、
LCD表示の復旧を確認する必要があります。
