# PCモニタリング

```powershell
python -m pip install -r pc/requirements.txt
python -m serial.tools.list_ports -v
```

ESP32のUSBを抜いたときと挿したときの一覧を比較し、対象機器の `VID:PID` と
`SER` または `LOCATION` を控えてください。Arduino IDEやPlatformIOなどの
シリアルモニターは閉じておきます。

## 起動方法

USBシリアル番号 `SER` が分かる場合は `--usb-serial` を使います。以下の値は例です。

```powershell
python -u pc/monitor.py --usb-serial 1234:5678 DASHBOARD01
```

`SER` が空で `LOCATION` が得られる場合は `--usb-location` を使います。同じUSB端子と
ハブ構成で使用してください。接続位置が変わった場合は一覧を取り直します。

```powershell
python -u pc/monitor.py --usb-location 1A86:7523 1-4.4
```

`--usb-location` は指定した物理経路にある同じVID/PIDの機器を選びます。対象機器用に
USB端子を決め、同じVID/PIDを持つ別の変換器をその端子に挿さないでください。
CH340のVID/PIDは変換器の情報です。自動検出では利用者が確認したシリアル番号または
接続位置も一致するポートが1件のときだけ開きます。候補が0件または複数件なら約2秒ごとに
再検出します。`SER` と `LOCATION` は一覧に表示された値をそのまま指定します。

機器のUSB識別情報を取得できない場合や、現在のCOM番号を直接使う場合は `--port` を指定します。
このモードの再試行先は毎回同じCOM番号です。番号が変わったときは引数を更新して起動し直します。

```powershell
python -u pc/monitor.py --port COM3
```

起動時は `--usb-serial`、`--usb-location`、`--port` のうち1つを指定します。

115200bpsで、`cpu` と `ram` の使用率を改行区切りのJSONとして送ります。
接続ごとにESP32の起動を2秒待ってから、約1秒間隔で最新の使用率を計測・送信します。
すでに動作しているESP32ファームウェアで使用できます。

ポートが見つからない場合やUSB切断・送信タイムアウト時は、ポートを閉じ、
2秒待って接続を試みます。自動検出モードでは毎回ポートを列挙し、同じ識別情報が
別のCOM番号で見つかった場合も送信を再開します。送信のタイムアウトは1秒です。
接続中・起動待機中・再接続待機中のいずれもCtrl+Cで終了できます。


## 実機確認手順（Windows / ESP32）

1. 対象機器を確認したUSB識別情報で自動検出を起動します。ログに対象のCOM番号が出て、
   コンソールのJSONとLCDの数値・バーが約1秒間隔で更新されることを確認します。
2. 対象機器のUSBを抜きます。プロセスが継続して約2秒ごとに再検出することを確認し、
   挿し直してJSON送信とLCD更新が自動再開することを確認します。対象機器を抜いた状態からの
   起動も試します。
3. COM番号が変わるケースを確認します。USBシリアル番号で選ぶ場合は別のUSB端子で
   同じ `SER` が得られるか確認します。接続位置で選ぶ場合はUSB端子を固定し、ドライバーが
   対応していればデバイスマネージャーのポート設定で空いているCOM番号に変更します。
   モニターを起動したまま再検出へ移行できた場合は、新しいCOM番号の接続ログ、JSON、LCD更新を
   確認します。ドライバーが番号変更にプログラムの終了を要求する場合は、新しいCOM番号を
   検出できることを再起動後に確認し、同一プロセスでの番号変更は未確認として記録します。
4. 別のUSBシリアル機器を同時に接続します。対象だけに接続し、対象を抜いたときは残った
   ポートを開かず再検出を続けることを確認します。同一の識別情報を持つ候補が複数ある場合は
   どの候補も開かず、複数一致のメッセージが出ます。
5. 手動指定で現在のCOM番号を開き、送信とLCD更新を確認します。送信中・起動待機中・再試行中に
   Ctrl+Cで終了し、再起動後に同じポートを開けることを確認します。

復旧しない場合は `python -m serial.tools.list_ports -v` の抜き差し前後の結果、
接続ログ、LCDの状態を確認します。ポートを開けない場合はシリアルモニターなどの占有も確認します。
